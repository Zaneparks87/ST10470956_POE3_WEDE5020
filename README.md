Zaneparks Hyper Website

1. Project Overview

Zaneparks Hyper is a multi-page retail website developed using HTML5, CSS3, and JavaScript. It allows users to explore products, learn about the store, submit enquiries, contact the business, and complete a demonstration order form.

2. Project Objectives

- Develop a multi-page retail website.
- Display products in an organised catalogue.
- Implement product search and price sorting.
- Create contact, enquiry, and order forms.
- Use JavaScript for interactivity and form validation.
- Design a responsive and user-friendly layout.
- Apply basic SEO and accessibility principles.

3. Technologies Used

- HTML5:Website structure and content.
- CSS3: Styling and responsive layouts.
- JavaScript: Interactive features and form validation.
- Visual Studio Code:Code editing.
- Git and GitHub: Version control and project hosting.

4. Website Pages

- index.html — Homepage.
- catalogue.html — Product catalogue with search and price sorting.
- about_us.html — Store information, mission, and vision.
- order.html — Demonstration order form.
- contact.html — Contact form.
- enquiry.html — Enquiry form and FAQ accordion.

 6. Main Features

- Navigation between website pages.
- Product catalogue with search and price sorting.
- Validated contact, enquiry, and order forms.
- FAQ accordion with expandable answers.
- Newsletter email validation.
- Embedded map, if configured.
- Responsive design for desktop and mobile devices.

7. Running the Website

1. Download or clone the repository.
2. Open the project folder in Visual Studio Code.
3. Open index.html in a browser or use the Live Server extension.
4. Navigate through the pages and test the features.

8. Testing

The website is tested for:

- Working navigation links.
- Correct loading of images, CSS, and JavaScript.
- Product search and price sorting.
- Form validation and feedback messages.
- FAQ accordion functionality.
- Desktop and mobile responsiveness.

9. Limitations

The forms provide client-side validation and feedback. Unless a backend or external service is connected, they do not send messages, save newsletter subscriptions, create real orders, or process payments.

 10. Future Improvements

- Implement secure order and payment processing.
- Integrate a newsletter subscription service.
- Improve performance, accessibility, and mobile navigation.
